# Asset Rights

This repository uses a default-deny media policy.

## Current inventory

| Path | Owner | Source | License | Redistribution | Status |
| --- | --- | --- | --- | --- | --- |
| `src/app/icon.svg` | Repository contributors | Original geometric mark | MIT | Allowed | APPROVED |
| Three.js scene geometry and CSS visuals | Repository contributors | Generated at runtime from source code | MIT | Allowed | APPROVED |

The `public/` directory intentionally contains no media in the initial release.

## Admission rule

A new image, audio file, video, font, PDF, model, or other binary asset may enter the repository only when its pull request records:

- path and SHA-256
- author or rights holder
- original source
- exact license or written authorization reference
- required attribution
- modifications made
- explicit permission to redistribute the file in source repositories

Private authorization evidence should remain in a protected archive. The public table may reference a non-sensitive evidence identifier.

## Excluded categories

Do not add commercial music, private photos, CVs, QR codes, customer screenshots, school or company marks, scraped platform media, unpublished research evidence, browser profiles, or generated assets whose redistribution terms cannot be verified.
