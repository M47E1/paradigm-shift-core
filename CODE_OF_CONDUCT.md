# Code of Conduct

We want collaboration here to be direct, useful, and respectful.

Contributors should discuss the work rather than the person, provide reproducible evidence for technical claims, respect privacy and intellectual-property boundaries, and make room for disagreement without harassment or intimidation.

Maintainers may edit, hide, or remove contributions that expose private information, contain abuse, or repeatedly disrupt constructive work. Serious concerns should be raised privately through the repository security channel.
